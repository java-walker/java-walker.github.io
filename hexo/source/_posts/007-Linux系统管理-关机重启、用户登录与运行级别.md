# Linux系统管理核心笔记：关机重启、用户登录与运行级别

> 一篇掌握Linux系统的基本管理操作

## 一、关机与重启命令

### 1.1 常用命令速查表

| 命令 | 功能 | 示例 |
| --- | --- | --- |
| `shutdown -h now` | **立即关机** | `shutdown -h now` |
| `shutdown -h 1` | **1分钟后关机**  （可带提示信息） | `shutdown -h 1 "系统将在1分钟后关机"` |
| `shutdown -r now` | **立即重启** | `shutdown -r now` |
| `halt` | 关机（作用和`shutdown -h`类似） | `halt` |
| `reboot` | 重启（作用和`shutdown -r`类似） | `reboot` |
| `sync` | 将内存数据**同步到磁盘** | `sync` |
### 1.2 ⚠️ 重要提醒：先sync再关机！

```
# 标准安全流程(老教材、旧方法)
```

为什么需要sync？

Linux为了提高性能，很多数据会暂存在内存中。如果不先sync就直接关机，内存中未写入磁盘的数据就会**丢失**，可能导致文件损坏。

> 现在的 `shutdown`、`reboot`、`halt` 命令**内部已经自动执行了sync**，所以直接使用这些命令通常也是安全的。但养成手动sync的好习惯，好吧，我没养成\[滑稽.jpg\]（有必要吗，不知道，就像Windows关机前先把应用给关掉）

## 二、用户登录与注销

### 2.1 基本使用规范

| 规范 | 说明 |
| --- | --- |
| **避免直接使用root** | root权限太大，一个误操作可能导致系统崩溃 |
| **推荐方式** | 用普通用户登录 → `su - 用户名` 切换到root |
| **注销用户** | 在命令行输入 `logout` 退出当前用户 |

## 三、运行级别（Runlevel）

### 3.1 传统SysV运行级别 vs Systemd Target

| 级别 | SysV Runlevel | systemd Target | 说明 |
| --- | --- | --- | --- |
| 0 | 关机 | `poweroff.target` | 系统关机 |
| 1 | 单用户模式 | `rescue.target` | **救援模式**  ，用于找回root密码等维护操作 |
| 2 | 多用户无网络 | — | 传统定义，较少使用 |
| 3 | **多用户有网络** | `multi-user.target` | **纯命令行服务器模式**  （最常用） |
| 4 | 保留未使用 | — | 系统保留 |
| 5 | **图形界面** | `graphical.target` | **桌面图形模式**  （个人电脑常用） |
| 6 | 重启 | `reboot.target` | 系统重启 |
> 💡 **最常用的是级别3和5**：服务器用3（命令行），个人桌面用5（图形界面）

3.4 常见应用场景

| 场景 | 操作 |
| --- | --- |
| **忘记root密码** | 进入运行级别1（单用户模式）重置密码 |
| **服务器部署** | 设置默认级别3，节省资源 |
| **个人桌面使用** | 设置默认级别5，使用图形界面 |
| **临时维护** | `init 3`   切到命令行进行维护，完成后 `init 5` 切回图形 |
