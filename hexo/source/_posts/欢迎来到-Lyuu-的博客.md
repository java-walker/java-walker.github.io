这是用 **Hexo** 搭建的全新博客的第一篇文章。

> 写博客的意义，不在于有多少人读，而在于把脑子里的想法逼出来、写清楚。

## 这个博客会写什么

- 编程与技术笔记（Java / 前端 / 工具链）
- AI 相关的实践与思考
- 生活里值得记录的小事

## 如何写一篇新文章

```bash
# 在 hexo 目录下
hexo new "文章标题"
# 然后编辑 source/_posts/文章标题.md
hexo generate   # 生成静态文件到 public/
hexo server     # 本地预览 http://localhost:4000
```

保持简单，持续输出。这就是开始。
