## 一、man命令：最权威的帮助手册

## 基本语法

```
man [命令或配置文件]
```

**功能**：获得命令或配置文件的详细帮助信息（manual，手册）

### 使用示例

```
# 查看ls命令的帮助信息
```

### man 页面导航

进入man页面后，使用以下快捷键浏览：

| 按键 | 功能 |
| --- | --- |
| `空格键` | 向下翻一页 |
| `Enter` | 向下翻一行 |
| `b` | 向上翻一页 |
| `/关键词` | 搜索关键词 |
| `q` | 退出man页面 |
### man的章节划分

man手册分为多个章节，可以通过章节号精确查找：

| 章节 | 内容 |
| --- | --- |
| 1 | 用户命令（最常用） |
| 2 | 系统调用 |
| 3 | C库函数 |
| 4 | 设备文件 |
| 5 | 配置文件格式 |
| 6 | 游戏 |
| 7 | 杂项 |
| 8 | 系统管理命令 |
```
man 5 passwd
```

## 二、help命令：内置命令的帮手

#   

## 基本语法

```
help 命令
```

**功能**：获取Shell**内置命令**的帮助信息

### 使用示例

```
# 查看cd命令的帮助信息
```

### ⚠️ man vs help 核心区别

| 对比项 | man | help |
| --- | --- | --- |
| 适用命令 | **外部命令**  （如 ls、cp、rm） | **Shell内置命令**  （如 cd、exit） |
| 信息详细程度 | 非常详细，包含参数、示例 | 简洁，只列出基本用法 |
| 退出方式 | 按 `q` 退出 | 直接显示在终端中 |
```
# 判断命令是内置还是外部
```

## 三、认识Shell内置命令 vs 外部命令

理解这个区别，你就能准确判断该用 `man` 还是 `help`。

| 类型 | 说明 | 常见命令 |
| --- | --- | --- |
| **内置命令**  （builtin） | 由Shell程序自身提供，不依赖外部文件 | `cd`  、`exit`、`echo`、`pwd`、`export` |
| **外部命令** | 独立可执行文件，位于 `/bin`、`/usr/bin` 等目录 | `ls`  、`cp`、`rm`、`mkdir`、`find` |
**快速判断方法：**

```
# 使用 type 命令判断
```

-   用 `help` 查内置命令
    
-   用 `man` 查外部命令
    
-   不确定时，先用 `help` 试试，不行再换 `man`
    

## 四、常见命令速查表

| 命令 | 类型 | 帮助方式 | 示例 |
| --- | --- | --- | --- |
| `ls` | 外部命令 | `man ls` | 查看文件列表 |
| `cd` | 内置命令 | `help cd` | 切换目录 |
| `cp` | 外部命令 | `man cp` | 复制文件 |
| `rm` | 外部命令 | `man rm` | 删除文件 |
| `mkdir` | 外部命令 | `man mkdir` | 创建目录 |
| `pwd` | 内置命令 | `help pwd` | 显示当前目录 |
| `echo` | 内置命令 | `help echo` | 输出内容 |
| `exit` | 内置命令 | `help exit` | 退出终端 |
| `passwd` | 外部命令 | `man passwd` | 修改密码 |
| `find` | 外部命令 | `man find` | 查找文件 |
## 五、互联网搜索：最直接的学习方式

> 💡 **名言**：man pages 是知识库，Google 是找答案的方式。

实际工作中，**99%的Linux问题都可以通过搜索解决**，而且速度比翻man手册快得多。

### 推荐搜索引擎

| 平台 | 适用场景 |
| --- | --- |
| **必应 / Google** | 通用搜索，中英文问题都能解决 |
| **CSDN** | 国内技术博客，有大量实操案例和踩坑记录 |
| **知乎** | 深度讨论、最佳实践、经验分享 |
| **博客园** | 基础教程、学习笔记 |
| **Stack Overflow** | 英文技术问答，高质量解决方案 |
| **AI助手（豆包/ChatGPT等）** | 直接提问，最直接不绕弯子的回答 |

## 六、信息获取优先级建议

在实际工作中，遇到不熟悉的命令或报错时，按以下顺序查找答案：

```
1️⃣ help 命令 → 先试试内置命令
```

### `--help` 补充说明

很多外部命令支持 `--help` 参数，输出比man更简洁：

```
ls --help
```

## 七、快速总结

| 命令 | 用途 | 适用对象 |
| --- | --- | --- |
| `man 命令` | 查看**详细**帮助手册 | 外部命令（ls、cp、rm等） |
| `help 命令` | 查看**简洁**帮助信息 | **内置命令**  （cd、exit、echo等） |
| `命令 --help` | 查看**简要**帮助 | 大部分外部命令 |
| `type 命令` | 判断命令是内置还是外部 | 所有命令 |
| `which 命令` | 查看外部命令的位置 | 外部命令 |
### 🎯 一句话记忆

-   查 **用法** → `man` 或 `--help`
    
-   查 **内置命令** → `help`
    
-   查 **答案** → Google / 必应 / AI
