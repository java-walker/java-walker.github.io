**示例输出解读：**

```

```

| 字段 | 含义 |
| --- | --- |
| `-rw-r--r--` | 文件类型和权限 |
| `1` | 硬链接数 |
| `root` | 所有者 |
| `root` | 所属组 |
| `1213` | 文件大小（字节） |
| `Feb 2 09:39` | 最后修改时间 |
> 💡 **隐藏文件**：Linux下以 `.` 开头的文件/目录是隐藏的，需要用 `ls -a` 才能看到。

## 八、命令速查卡片

| 命令 | 功能 | 示例 |
| --- | --- | --- |
| `pwd` | 显示当前目录 | `pwd` |
| `ls -al` | 列出所有文件的详细信息 | `ls -al /home` |
| `cd ~` | 回到家目录 | `cd ~` |
| `mkdir -p` | 递归创建目录 | `mkdir -p a/b/c` |
| `rmdir` | 删除空目录 | `rmdir empty_dir` |
| `touch` | 创建空文件 | `touch file.txt` |
| `cp -r` | 递归复制目录 | `cp -r dir1 dir2` |
| `mv` | 移动/重命名 | `mv old.txt new.txt` |
| `rm -rf` | 强制递归删除 | `rm -rf /tmp/cache` |
| `cat -n` | 带行号显示内容 | `cat -n file` |
| `more` | 分页查看 | `more file` |
| `less` | 更强大分页 | `less file` |
| `echo` | 输出内容 | `echo "hello"` |
| `head -n 5` | 显示前5行 | `head -n 5 file` |
| `tail -f` | 实时追踪 | `tail -f log` |
| `>` | 覆盖重定向 | `echo a > file` |
| `>>` | 追加重定向 | `echo b >> file` |
| `ln -s` | 创建软链接 | `ln -s /root link` |
| `history` | 查看历史 | `history` |
| `!5` | 执行第5条历史 | `!5` |
