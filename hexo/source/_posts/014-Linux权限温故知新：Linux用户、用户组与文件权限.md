## 一、权限字符串完整拆解

### 1.1 10位权限格式

```
-rw-r--r--. 1 root root 1213 Feb 2 09:39 abc.txt
```

格式：`[1位文件类型][9位权限]`

| 位置 | 含义 | 示例 |
| --- | --- | --- |
| 第1位 | **文件类型** | `-`  （普通文件）`d`（目录）`l`（软链接）`c`（字符设备）`b`（块设备） |
| 第2-4位 | **属主权限（u）** | `rw-` |
| 第5-7位 | **属组权限（g）** | `r--` |
| 第8-10位 | **其他用户权限（o）** | `r--` |
**示例解读**：`-rw-r--r--`

-   `-` → 普通文件
    
-   `rw-` → 属主可读可写不可执行
    
-   `r--` → 同组用户只读
    
-   `r--` → 其他用户只读
    

### 1.2 文件类型标识大全

| 符号 | 类型 | 说明 |
| --- | --- | --- |
| `-` | 普通文件 | 文本、二进制、数据文件 |
| `d` | 目录 | 文件夹 |
| `l` | 软链接 | 符号链接（快捷方式） |
| `c` | 字符设备 | 键盘、鼠标、串口 |
| `b` | 块设备 | 硬盘、U盘 |
| `s` | 套接字 | 进程间通信 |
| `p` | 管道 | FIFO文件 |
### 1.3 rwx对文件和目录的区别（核心难点！）

| 权限 | 对**普通文件**的作用 | 对**目录**的作用 |
| --- | --- | --- |
| **r（读）** | 查看文件内容（`cat`、`less`） | **列出目录内容**  （`ls`） |
| **w（写）** | 修改/覆盖文件内容 | **创建、删除、重命名**  目录内文件（需配合x） |
| **x（执行）** | 运行脚本/程序 | **进入目录**  （`cd`） |
> ⚠️ **重点理解**：对目录有`w`权限，**不需要**对目录内的文件有`w`权限，就能删除该文件！因为删除文件是修改**目录内容**，不是修改文件本身。

**目录权限组合实战理解：**

| 目录权限 | 能否`ls` | 能否`cd`进入 | 能否删除/创建文件 |
| --- | --- | --- | --- |
| `r--`  （只读） | ✅ 能（但看不到属性细节） | ❌ 不能 | ❌ 不能 |
| `-w-`  （只写，无x） | ❌ 不能 | ❌ 不能 | ❌ 不能（没有x连进入都不行） |
| `--x`  （只执行） | ❌ 不能 | ✅ 能 | ❌ 不能 |
| `rw-`  （读写，无x） | ✅ 能 | ❌ 不能 | ❌ 不能 |
| `rwx`  （全开） | ✅ 能 | ✅ 能 | ✅ 能 |
| `-wx`  （写+执行，无读） | ❌ 不能 | ✅ 能 | ✅ 能（知道文件名才能操作） |
> 💡 **实战启发**：目录的`x`权限是进入目录的“门票”，没有了它，`r`和`w`都无法发挥作用。这就是为什么文件夹至少需要`r-x`才能正常浏览访问。

六、特殊权限（进阶）

除了基础的rwx，Linux还有三个**特殊权限**：

### 6.1 SUID（Set User ID）— 4xxx

**作用**：用户执行该文件时，**临时获得文件所有者权限**，而非执行者自己的权限。

```
# 典型示例：/usr/bin/passwd
```

6.2 SGID（Set Group ID）— 2xxx

**作用**：

-   **对文件**：用户执行时获得文件**所属组**权限
    
-   **对目录**：在该目录下新建的文件**继承目录的所属组**（而非创建者的组）
    
    ```
    # 设置SGID
    ```

6.3 Sticky Bit（粘滞位）— 1xxx

**作用**：在公共目录中，**只有文件所有者、目录所有者或root才能删除文件**（其他人即使有写权限也不能删）。

```
# 典型示例：/tmp 目录
```

特殊权限速查表

| 特殊权限 | 数字位 | 字符表现 | 典型用途 |
| --- | --- | --- | --- |
| SUID | 4xxx | `s`  替代属主的`x` | passwd命令 |
| SGID | 2xxx | `s`  替代属组的`x` | 共享目录 |
| Sticky Bit | 1xxx | `t`  替代other的`x` | /tmp目录 |
> 💡 **设置技巧**：将特殊权限数字放在普通权限前，如 `chmod 4755 file`（SUID + rwxr-xr-x）

## 七、权限最佳实践（避坑指南）

| 最佳实践 | 说明 |
| --- | --- |
| **目录权限 ≥ 755** | 目录有执行(x)才能cd进入，建议至少755 |
| **配置文件权限 644** | 只有属主可写，防止误修改 |
| **脚本权限 755** | 需要执行权限 |
| **敏感文件 600** | 如私钥、密码文件，仅属主可读写 |
| **共享目录 1777** | 加粘滞位，防止他人删除 |
| **Web目录 755/644** | 目录755，文件644，避免安全风险 |
| **避免使用777** | 任何人可写是安全灾难！ |
## 八、命令速查卡片

| 操作 | 命令 |
| --- | --- |
| 查看文件详情 | `ll`   或 `ls -l` |
| 查看所有文件（含隐藏） | `ls -al` |
| 数字改权限 | `chmod 755 file` |
| 字符改权限 | `chmod u+x file` |
| 递归改权限 | `chmod -R 755 /dir` |
| 修改属主 | `chown user1 file` |
| 修改属组 | `chgrp group1 file` |
| 同时修改属主+属组 | `chown user1:group1 file` |
| 递归修改 | `chown -R user1:group1 /dir` |
| 创建组 | `groupadd grp` |
| 创建用户并指定组 | `useradd -g grp user1` |
| 修改用户组 | `usermod -g grp user1` |
| 删除用户（含家目录） | `userdel -r user1` |
| 查看所有用户 | `tail /etc/passwd` |
| 查看所有组 | `tail /etc/group` |
