    009 Linux常用文件目录命令：文件目录操作一本通

    发表于 2026-07-06 更新于 2026-07-23 分类于 运维

    原文转载自微信公众号「walker-行者」Linux 系列。

    掌握这些命令，Linux日常操作就掌握了80%

    一、目录操作命令

    1.1 pwd — 显示当前目录

    1.2 ls — 列出目录内容

    示例输出解读：

    字段 含义
    -rw-r--r-- 文件类型和权限
    1 硬链接数
    root 所有者
    root 所属组
    1213 文件大小（字节）
    Feb 2 09:39 最后修改时间

    💡 隐藏文件：Linux下以 . 开头的文件/目录是隐藏的，需要用 ls -a 才能看到。

    1.3 cd — 切换目录

    路径类型：

    路径类型 示例 说明
    绝对路径 cd /etc/nginx 从根目录开始完整路径
    相对路径 cd ../tom 相对于当前目录的路径
    家目录 cd ~ 当前用户的家目录

    二、目录创建与删除

    2.1 mkdir — 创建目录

    2.2 rmdir — 删除空目录

    💡 删除非空目录：需要用 rm -rf（见下文rm命令）

    三、文件操作命令

    3.1 touch — 创建空文件/更新时间戳

    3.2 cp — 复制文件或目录

    3.3 mv — 移动/重命名

    3.4 rm — 删除文件或目录

    ⚠️ 危险警告：rm -rf 是非常强大的命令，使用前务必确认路径正确，尤其是 rm -rf /* 会删除整个系统！

    四、查看文件内容

    4.1 cat — 一次性显示全部内容

    ⚠️ cat 适合查看小文件，大文件会刷屏。

    4.2 more — 分页查看（可交互）

    💡 管道配合：cat -n /etc/profile | more 带行号分页查看

    4.3 less — 更强大的分页查看

    💡 less vs more：less 不会一次性加载整个文件，查看大文件效率更高，功能也更丰富。

    4.4 head — 查看文件头部

    4.5 tail — 查看文件尾部

    🎯 实战场景：tail -f 是运维排查问题的必备命令，可以实时查看日志输出。

    五、输出与重定向

    5.1 echo — 输出到控制台

    5.2 > 和 >> — 重定向

    符号 功能 示例
    > 覆盖 写入 ls -l /home > list.txt
    >> 追加 写入 date >> list.txt
    2> 错误重定向 ls 不存在 2> error.log

    六、链接命令

    ln -s — 创建软链接（快捷方式）

    💡 软链接 vs 硬链接：

    • 软链接：相当于快捷方式，可以跨文件系统，删除原文件则失效

    • 硬链接：相当于文件的别名，不能跨文件系统，删除原文件仍有效

    八、命令速查卡片

    命令 功能 示例
    pwd 显示当前目录 pwd
    ls -al 列出所有文件的详细信息 ls -al /home
    cd ~ 回到家目录 cd ~
    mkdir -p 递归创建目录 mkdir -p a/b/c
    rmdir 删除空目录 rmdir empty_dir
    touch 创建空文件 touch file.txt
    cp -r 递归复制目录 cp -r dir1 dir2
    mv 移动/重命名 mv old.txt new.txt
    rm -rf 强制递归删除 rm -rf /tmp/cache
    cat -n 带行号显示内容 cat -n file
    more 分页查看 more file
    less 更强大分页 less file
    echo 输出内容 echo "hello"
    head -n 5 显示前5行 head -n 5 file
    tail -f 实时追踪 tail -f log
    > 覆盖重定向 echo a > file
    >> 追加重定向 echo b >> file
    ln -s 创建软链接 ln -s /root link
    history 查看历史 history
    !5 执行第5条历史 !5
