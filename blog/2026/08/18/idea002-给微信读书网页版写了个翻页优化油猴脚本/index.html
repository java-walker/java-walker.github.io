给微信读书网页版写了个翻页优化油猴脚本

发表于 2026-08-19 更新于 2026-10-26 分类于 技术

起因很简单：在微信读书网页版看书，翻页只能点右下角的箭头或者按它认的那几个键，我用空格和滚轮翻习惯了，它不认。

事情是这样的

我平时在浏览器里用微信读书（weread.qq.com）看书，阅读器页面翻页的方式很有限：鼠标点按钮，或者按方向键。但我看网页的习惯是空格键往后翻、滚轮上下滚——这套习惯在哪都好使，唯独微信读书不认。

空格在它那里要么没反应，要么触发了页面里别的行为。每翻一页都要挪鼠标去点按钮，看一天书手真的很累。

这种小事不值得跟官方提需求，但自己动手半小时就搞定了。写了个 Tampermonkey 脚本，就是 weread-web-optimizer。

它做了什么

就四件事，全是翻页：

操作 效果
空格 / 回车（含小键盘回车） 向后翻页
鼠标滚轮向下 向后翻页
鼠标滚轮向上 向前翻页

装好之后，看书的姿势就恢复成了我刷其他网页的样子：手放滚轮上，滚一下翻一页，想键盘翻就敲空格。

几个实现上的小细节

  • 输入框里不拦截按键。会先判断焦点是不是在输入框 / 文本域里，是的话直接放行，免得你在搜索框里打字打着打着突然翻页。
  • 长按空格只翻一次。不做按住连翻，防止手一抖从第三章翻到第七章。
  • 滚轮做了 200ms 节流。触控板和惯性滚动一次能吐十几个滚轮事件，不节流的话一滚就是好几页。阈值在脚本里可调。
  • 只作用于 weread.qq.com，match 规则卡死了它的域名和 /web/reader/ 路径，其他网站一律不碰。

装在哪

  • 仓库：java-walker/weread-web-optimizer
  • Greasy Fork 上也有：微信阅读网页版翻页优化，走 Greasy Fork 能自动更新，也方便别人搜到。

装法就是常规油猴脚本的装法：浏览器先装 Tampermonkey 扩展，然后点仓库 README 里的 Install 徽章（走 jsDelivr CDN，国内直连），确认安装即可。

最后

这类脚本本质上是在帮自己把「网页的默认操作习惯」掰回自己顺手的形状。代码不长，百来行，ESLint 过一遍就提交了。微信读书网页版哪天改了翻页的实现方式它可能会失效——失效了再改呗，反正生成这个脚本的成本比看一天书挪几百次鼠标低多了。
